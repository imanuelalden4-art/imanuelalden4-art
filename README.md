# `AI × DEVELOPMENT`

AI is part of my development workflow.

Depending on the project, AI may contribute around **20–50% of the code**, mainly as a development assistant.

I use it for:

* Exploring ideas
* Debugging
* Understanding unfamiliar concepts
* Testing different approaches
* Accelerating implementation
* Learning through experimentation

But generated code is not the finish line.

I still focus on understanding the architecture, testing the system, fixing problems, and deciding how the final implementation should work.

**AI helps me build faster. Understanding helps me build better.**
